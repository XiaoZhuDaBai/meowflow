## 二、核心使用流程

### 2.1 流程一：从零创建工作流

**适用场景**：用户需要从空白开始构建一个新的工作流

```
步骤 1：点击「新建工作流」按钮
        ↓
步骤 2：进入可视化编辑器，自动创建一个「Webhook触发器」作为起点
        ↓
步骤 3：从左侧节点面板拖拽节点到画布
        ↓
步骤 4：点击节点，在右侧配置面板设置参数
        ↓
步骤 5：连接节点之间的连线
        ↓
步骤 6：点击「测试运行」验证工作流
        ↓
步骤 7：查看执行日志，确认无误后点击「保存」
        ↓
步骤 8：点击「发布」使工作流生效
```

**详细操作说明**：

#### 步骤 1 - 进入编辑器

1. 从侧边栏点击「工作流」，进入工作流列表
2. 点击页面右上角蓝色按钮「新建工作流」
3. 系统自动跳转到 `/editor` 页面

#### 步骤 2 - 添加触发器

编辑器默认已创建一个「Webhook触发器」节点，作为工作流的起点。

#### 步骤 3 - 添加业务节点

1. 点击画布上方的「+ 添加节点」按钮，或直接点击节点面板
2. 节点面板展示5大类节点：
   - **触发器**：Webhook、定时、表单、邮件
   - **AI能力**：LLM对话、AI分类、信息提取、文本总结、知识库检索
   - **流程控制**：条件分支、循环节点、并行执行、等待节点
   - **工具**：HTTP请求、数据库、代码执行、变量赋值
   - **通知**：钉钉通知、企业微信、邮件发送、短信通知
3. 点击需要的节点类型，即可在画布中央添加节点
4. 拖拽节点可调整位置

#### 步骤 4 - 配置节点

1. 点击画布上的节点，选中后右侧配置面板显示节点配置
2. 配置面板包含3个Tab：
   - **配置**：节点名称、模型选择、提示词等核心参数
   - **输入**：查看该节点的输入变量
   - **输出**：查看该节点的输出变量
3. 不同类型节点有不同的配置项

#### 步骤 5 - 连接节点

1. 鼠标悬停在节点边缘，显示连接点
2. 拖拽连接点到目标节点，建立连线
3. 点击连线可选中并删除

#### 步骤 6 - 测试运行

1. 点击顶部工具栏「测试运行」按钮
2. 系统开始模拟执行工作流
3. 底部日志面板实时显示执行过程
4. 每个节点会显示运行状态（运行中/成功/失败）

#### 步骤 7 - 保存

1. 点击顶部「保存」按钮
2. 系统保存当前工作流定义
3. 工作流列表显示新创建的工作流卡片

#### 步骤 8 - 发布

1. 点击顶部「发布」按钮
2. 工作流状态变为「运行中」
3. Webhook触发器生成可调用的URL

### 2.2 流程二：使用模板创建工作流

**适用场景**：用户希望利用预置模板快速创建工作流

```
步骤 1：从侧边栏点击「模板」
        ↓
步骤 2：进入模板市场，浏览可用模板
        ↓
步骤 3：通过分类或搜索找到需要的模板
        ↓
步骤 4：点击「预览」查看模板详情
        ↓
步骤 5：点击「使用模板」创建工作流
        ↓
步骤 6：系统自动创建工作流并跳转到编辑器
        ↓
步骤 7：根据实际需求修改节点配置
        ↓
步骤 8：保存并发布工作流
```

**模板分类**：

| 分类 | 模板示例 | 适用场景 |

### 2.3 流程三：查看和管理工作流

**适用场景**：用户需要查看、修改、复制或删除已有工作流

#### 查看工作流

1. 进入工作流列表
2. 点击任意工作流卡片上的「详情」按钮
3. 进入详情页，查看：
   - 工作流基本信息（名称、描述、版本）
   - 统计数据（总执行、成功率、平均耗时、总成本）
   - 节点定义表格

#### 编辑工作流

1. 点击工作流卡片上的「编辑」按钮
2. 进入编辑器，加载该工作流的完整定义
3. 可修改任意节点或配置
4. 保存后自动更新版本号

#### 其他操作

| 操作 | 入口 | 说明 |
|------|------|------|
| 复制 | 卡片右上角「···」菜单 | 创建当前工作流的副本 |
| 发布 | 卡片右上角「···」菜单 | 启动工作运行 |
| 停止 | 卡片右上角「···」菜单 | 停止工作流运行 |
| 删除 | 卡片右上角「···」菜单 | 删除工作流（需确认） |

---

### 2.4 流程四：执行和监控

**适用场景**：用户需要运行工作流并查看执行结果

#### 执行工作流

**方式一：通过Webhook触发**

1. 发布工作流后，复制系统生成的Webhook URL
2. 通过任何HTTP客户端发送POST请求到该URL
3. 请求Body作为工作流的输入参数
4. 响应返回工作流执行结果

**方式二：通过编辑器测试运行**

1. 在编辑器中点击「测试运行」
2. 可在弹窗中填写测试输入参数
3. 实时查看执行日志

#### 查看执行日志

1. 从侧边栏点击「日志」
2. 进入执行日志列表页面
3. 可按工作流名称、状态、时间筛选
4. 点击单条日志查看详细执行信息

## 五、完整用户场景示例

### 场景：电商运营 - 每日爆款商品分析

**背景**：小美是某电商公司的运营，需要每天早上9点自动分析昨日销售数据，生成爆款商品报告，并发送至钉钉群。

**操作流程**：

#### 1. 创建工作流

1. 小美登录喵流，点击「新建工作流」
2. 进入编辑器，系统已创建「Webhook触发器」

#### 2. 添加节点

1. 点击「添加节点」，选择「触发器 > 定时触发」
2. 配置Cron表达式：`0 9 * * *`（每天9点执行）
3. 添加「工具 > HTTP请求」节点，配置获取昨日销售数据的API
4. 添加「AI能力 > 文本总结」节点，配置分析爆款的Prompt
5. 添加「通知 > 钉钉通知」节点，配置钉钉群Webhook

#### 3. 连接节点

```
定时触发 → HTTP请求 → 文本总结 → 钉钉通知
```

#### 4. 测试运行

1. 点击「测试运行」
2. 在输入框填写测试的销售数据JSON
3. 查看执行日志，确认每个节点正常执行
4. 检查钉钉群收到测试消息

#### 5. 发布

1. 点击「保存」保存工作流
2. 点击「发布」启动工作流
3. 每天9点系统自动执行，生成报告发送至钉钉群

## 六、前后端交互流程

### 6.1 API调用链路

```
┌─────────────┐    1. GET /api/workflows     ┌─────────────┐
│   前端页面   │ ──────────────────────────▶ │   后端API   │
│  WorkflowList│◀────────────────────────── │   /workflow │
└─────────────┘    2. 返回工作流列表         └─────────────┘

┌─────────────┐    3. POST /api/workflows    ┌─────────────┐
│   前端页面   │ ──────────────────────────▶ │   后端API   │
│   Editor    │◀────────────────────────── │   /workflow │
└─────────────┘    4. 返回保存结果           └─────────────┘

┌─────────────┐    5. POST /api/workflows/:id/execute ┌─────────────┐
│   前端页面   │ ────────────────────────────────────▶ │   后端API   │
│   Editor    │◀──────────────────────────────────── │   /execute  │
└─────────────┘    6. 返回执行结果 / SSE流式日志       └─────────────┘
```

### 6.2 核心API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/workflows` | GET | 获取工作流列表 |
| `/api/workflows/:id` | GET | 获取工作流详情 |
| `/api/workflows` | POST | 创建工作流 |
| `/api/workflows/:id` | PUT | 更新工作流 |
| `/api/workflows/:id` | DELETE | 删除工作流 |
| `/api/workflows/:id/publish` | POST | 发布工作流 |
| `/api/workflows/:id/execute` | POST | 执行工作流 |
| `/api/workflows/:id/logs` | GET | 获取执行日志 |
| `/api/templates` | GET | 获取模板列表 |
| `/api/templates/:id/use` | POST | 使用模板创建 |
| `/api/statistics` | GET | 获取统计数据 |
