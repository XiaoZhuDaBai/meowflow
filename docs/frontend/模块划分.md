## 一、项目概述

### 1.1 项目定位

喵流前端是一个面向业务人员的 **AI 工作流可视化编排平台**，核心场景是：

- 通过拖拽方式编排 AI 工作流
- 无需编程即可构建企业级自动化流程
- 实时监控工作流执行状态

### 1.2 技术选型

| 技术类别 | 选型方案 | 版本要求 |
|---------|---------|---------|
| 核心框架 | Vue 3 + TypeScript | ^3.4 / ^5.0 |
| UI 组件库 | Element Plus | ^2.5 |
| 流程图引擎 | @antv/g6 | ^5.0 |
| 状态管理 | Pinia | ^2.1 |
| 路由管理 | Vue Router | ^4.2 |
| 构建工具 | Vite | ^5.0 |
| HTTP 客户端 | Axios | ^1.6 |
| 图表库 | ECharts | ^5.5 |
| 图标库 | Font Awesome | ^6.4 |

## 八、状态管理 (Pinia Stores)

### 8.1 Store 划分

| Store | 职责 | 主要状态 |
|-------|------|---------|
| `useWorkflowStore` | 工作流管理 | 列表、当前工作流 |
| `useCanvasStore` | 画布状态 | 缩放、平移位置、选中节点 |
| `useNodeStore` | 节点操作 | 节点数据、配置模板 |
| `useUserStore` | 用户信息 | 用户信息、Token |
| `useSettingsStore` | 系统设置 | AI模型配置、主题 |

### 8.2 核心 Store 示例

```typescript
// stores/workflow.ts
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';
import { getWorkflows, getWorkflow, saveWorkflow } from '@/api/workflow';

export const useWorkflowStore = defineStore('workflow', () => {
  // State
  const workflows = ref<Workflow[]>([]);
  const currentWorkflow = ref<Workflow | null>(null);
  const loading = ref(false);

  // Getters
  const runningWorkflows = computed(() =>
    workflows.value.filter(w => w.status === 'running')
  );

  // Actions
  async function fetchWorkflows() {
    loading.value = true;
    try {
      workflows.value = await getWorkflows();
    } finally {
      loading.value = false;
    }
  }

  async function save(id: string, data: Partial<Workflow>) {
    await saveWorkflow(id, data);
  }

  return { workflows, currentWorkflow, loading, runningWorkflows, fetchWorkflows, save };
});
```
