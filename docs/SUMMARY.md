## 🎯 核心设计亮点（参考Ragent）

### 1. 三层架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        喵流三层架构                                  │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  业务服务层 - WorkflowService / TemplateService / ExecutorService        │
│                                    │                                     │
│                                    ▼                                     │
│  节点执行层 - NodeRegistry / LLMExecutor / SearchExecutor / MCPTool     │
│                                    │                                     │
│                                    ▼                                     │
│  基础设施层 - 线程池 / 限流熔断 / 链路追踪 / 上下文透传               │
│                                                                          │
│  核心思想：换模型不改业务，换节点不改引擎，换业务不改基础设施            │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2. LLM节点（模型路由+熔断）

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        模型路由与容错                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  用户请求 → 意图识别 → 模型路由 → 熔断器 → 首选模型 → 备选模型          │
│                                    │                                     │
│                                    ▼                                     │
│                    三态熔断：CLOSED → OPEN → HALF_OPEN                 │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3. 知识库检索（多路检索）

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        多路检索架构                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  用户问题 → 问题预处理 → 向量检索+关键词检索+知识图谱 → 后处理链 → 结果  │
│                                    │                                     │
│                                    ▼                                     │
│                    去重 → 融合排序 → 重排序 → 质量过滤              │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 4. 执行引擎（DAG拓扑排序）

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        执行引擎流程                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  触发请求 → 加载定义 → 解析DAG → 拓扑排序 → 节点执行 → 返回结果       │
│                                    │                                     │
│                                    ▼                                     │
│                    Kahn算法：入度为0优先 → BFS → 拓扑序                │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

## 🚀 开发指引

### MVP阶段开发顺序

```
第1周：项目脚手架
├─ Spring Boot项目初始化
├─ 三层架构搭建
├─ common模块封装
└─ 数据库表创建

第2-3周：执行引擎核心
├─ DAG拓扑排序
├─ NodeRegistry节点注册中心
├─ 执行上下文设计
└─ 基础节点实现

第4-5周：LLM节点
├─ ChatClient抽象
├─ 模型路由
├─ 三态熔断器
└─ 多模型支持

第6周：知识库检索节点
├─ 多路检索设计
├─ 后处理器链
└─ Rerank集成

第7-8周：可视化编辑器
├─ 前端项目搭建
├─ 画布组件
├─ 节点拖拽
└─ 配置面板

第9-10周：完善与测试
├─ 触发器实现
├─ 通知节点
├─ 监控日志
└─ 模板市场
```

### 技术难点

| 难点 | 解决方案 | 参考 |
|------|----------|------|
| 可视化编辑器 | G6.js / LogicFlow | Dify |
| DAG拓扑排序 | Kahn算法 | 算法基础 |
| 模型路由 | 策略模式+熔断器 | Ragent |
| 多路检索 | 策略模式+责任链 | Ragent |
| 线程池设计 | 8个专用+TLL透传 | Ragent |
