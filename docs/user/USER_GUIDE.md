## 工作流设计

### 基本结构

工作流由 **节点** + **边** 组成的有向无环图 (DAG)：

```
[触发器] → [数据处理] → [AI 处理] → [结束节点]
```

### 节点分类

| 类型 | 说明 | 示例 |
|------|------|------|
| 触发器 | 流程入口 | Webhook、定时、表单 |
| AI | AI 处理 | LLM、知识库、Agent |
| 逻辑 | 控制流 | IF、循环、并行 |
| 工具 | 集成调用 | HTTP、数据库、代码 |
| 通知 | 消息推送 | 飞书、邮件、短信 |
| 结束 | 流程终止 | END、Answer |

## 变量系统

### 变量引用

使用 `{{节点名.字段}}` 引用上游输出：

```
{{trigger.text}}          # 触发器输入
{{llm.answer}}            # LLM 输出
{{search.documents}}      # 知识库结果
```

### 嵌套引用

支持深度访问：

```
{{user.profile.name}}
{{search.documents[0].content}}
```

### 上下文变量

特殊变量：
- `$item` - 循环当前项
- `$index` - 循环索引
- `$now` - 当前时间戳
- `$env` - 环境变量

---

## 条件分支

### IF 节点

```
表达式: {{trigger.amount}} > 1000
真分支: [大额处理]
假分支: [小额处理]
```

### Switch 节点

```
字段: {{classify.category}}
分支:
  - FAQ: [FAQ 节点]
  - 投诉: [投诉节点]
  - 默认: [通用节点]
```

## 循环与并行

### 循环 (Iteration)

对数组每个元素执行：

```
输入: {{search.documents}}  // 数组
循环变量: $item

[$item] → [LLM 处理] → [汇总]
```

### 并行 (Fork + Join)

```
              ┌─ [节点A] ─┐
[触发] → Fork ┼─ [节点B] ─┼→ Join → [汇总]
              └─ [节点C] ─┘
```

Join 策略：
- `all` - 等待所有
- `any` - 任一完成
- `n` - 完成 N 个

## 子工作流

### 引用子工作流

在父工作流中使用 **子工作流节点**，指定目标工作流 ID。

### 传递参数

```
父: {{llm.result}} → 子: input.data
子: {{output}} → 父: subWorkflow.output
```

### 适用场景

- 通用逻辑复用
- 复杂业务拆分
- 团队协作

## LLM 节点

### 模型选择

| 模型 | 用途 | 单价 (USD/1K) |
|------|------|---------------|
| gpt-4o | 复杂推理 | $0.005/$0.015 |
| gpt-4o-mini | 日常任务 | $0.00015/$0.0006 |
| claude-3.5-sonnet | 长文本 | $0.003/$0.015 |
| glm-4-flash | 中文 | ¥0.001 |

### Prompt 技巧

1. **明确角色**: "你是一名专业律师"
2. **给出示例**: 提供 1-3 个 few-shot 示例
3. **结构化输出**: "请用 JSON 格式返回"
4. **约束条件**: "不超过 200 字"

## Agent 系统

### Function Calling (推荐)

```
[Agent 节点]
  策略: function-calling
  模型: gpt-4o
  工具: [搜索, HTTP, 计算器]
  最大循环: 10
```

Agent 会**自动选择工具**，无需手动编排。

### ReAct

适用于不支持 function-calling 的模型：

```
[Agent 节点]
  策略: ReAct
  模型: qwen-plus
```

## 知识库管理

### 创建知识库

1. 进入 **知识库** → **新建**
2. 选择类型 (文本/FAQ/表格)
3. 上传文档 (PDF/Word/Markdown)
4. 配置切片策略
5. 等待向量化完成

### 切片策略

| 策略 | 适用 |
|------|------|
| 通用 (500字) | 默认 |
| 长文档 (1000字) | 论文 |
| 短文本 (200字) | FAQ |
| 按段落 | 代码 |

### 检索模式

- **向量检索**: 语义相似度
- **关键词检索**: 精确匹配
- **混合检索**: RRF 重排 (推荐)

## 断点调试

### 进入调试模式

1. 按 **Ctrl+D** 或点击调试开关
2. 在任意节点上点击 → 设置断点

### 调试控制

- **▶ 继续** - 执行到下一个断点
- **⏭ 单步** - 执行下一节点后暂停
- **⏹ 停止** - 终止调试

### 变量查看

右侧 **变量查看器** 实时显示：
- 当前节点输入
- 当前节点输出
- 上游所有节点输出

## 告警规则

### 配置告警

1. 进入 **告警规则** → **新建**
2. 选择指标 (QPS/成功率/延迟/成本)
3. 设置阈值条件
4. 配置通知渠道
5. 启用/禁用

### 通知渠道

- 飞书机器人
- 钉钉机器人
- 邮件
- 短信
- Webhook

### 静默规则

避免重复告警：
```
静默条件: 同类告警 30 分钟内只发一次
```
