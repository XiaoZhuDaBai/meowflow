# 🚀 喵流快速上手

> 5 分钟搭建你的第一个 AI 工作流

---

## 📦 什么是喵流？

喵流 (MeowFlow) 是一个**可视化 AI 工作流编排平台**，让你无需写代码就能构建 AI 自动化：
- ✨ **拖拽式编辑器** - 像搭积木一样编排工作流
- 🤖 **AI 节点** - 内置 LLM、知识库检索、Agent 等
- 🔌 **丰富集成** - HTTP、Webhook、飞书、邮件、数据库
- 📊 **可观测性** - 实时日志、断点调试、成本统计

---

## ⚡ 30 秒极速体验：客服自动回复

### 第 1 步：登录

打开 [http://localhost:3000](http://localhost:3000)，使用默认账号登录：
```
用户名: admin
密码: admin123
```

### 第 2 步：选择模板

点击首页的 **「客服自动回复」** 模板卡片。

### 第 3 步：一键应用

点击 **「使用此模板」** → 工作流自动加载到画布。

### 第 4 步：测试运行

点击右上角 **「试运行」** 按钮，输入测试消息：
```json
{
  "body": {
    "text": "我的订单什么时候发货？",
    "userId": "user_001"
  }
}
```

### 第 5 步：查看结果

右侧实时显示节点执行日志，最后一个节点输出 AI 回复。

🎉 **恭喜！** 你已经完成第一个 AI 工作流！

## 🎯 进阶：搭建自定义工作流

### 场景：员工智能问答

**需求**：员工向 IM 机器人提问，自动从知识库检索答案。

#### 第 1 步：新建工作流

点击 **「+ 新建工作流」** → 名称输入 `员工助手` → 选择空白画布。

#### 第 2 步：拖入节点

左侧节点面板，按需拖入以下节点到画布：

```
[消息触发器] → [问题分类] → [知识库检索] → [LLM 回答] → [发送回复]
```

#### 第 3 步：配置 LLM 节点

双击 **「LLM 回答」** 节点：

| 字段 | 值 |
|------|---|
| 模型 | GPT-4o Mini |
| 系统提示 | 你是企业知识助手，礼貌专业 |
| 用户提示 | 问题：{{trigger.text}}<br>参考：{{search.context}} |
| 温度 | 0.5 |
| 输出键 | answer |

#### 第 4 步：连接节点

按顺序连线：触发器 → 分类 → 检索 → LLM → 发送。

#### 第 5 步：测试与发布

点击 **「试运行」** 验证 → 点击 **「发布」** 即可上线。

## 🔑 核心概念

### 工作流 (Workflow)
由节点 + 连线组成的有向无环图 (DAG)，定义 AI 自动化的执行逻辑。

### 节点 (Node)
工作流的基本单位，分为 5 大类：
- **触发器**：Webhook / 定时 / 表单 / IM 消息
- **AI**：LLM / Agent / 知识库检索
- **逻辑**：条件 / 循环 / 分支
- **工具**：HTTP / 数据库 / 代码 / MCP 工具
- **通知**：飞书 / 邮件 / 短信

### 变量引用 `{{...}}`

节点之间传递数据使用 `{{节点名.字段}}` 语法：
```
{{trigger.text}}           # 触发器输入
{{search.context}}         # 知识库检索结果
{{llm.answer}}             # LLM 输出
```

### 上下文透传
所有节点共享**执行上下文**，上游节点的输出自动作为下游节点的输入。
