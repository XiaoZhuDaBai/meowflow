# 喵流常见问题 (FAQ)

> 30 个高频问题解答

---

## 🚀 入门篇

### Q1: 喵流和 Dify / Coze 的区别是什么？

**A**: 喵流在以下方面有差异化优势：

| 维度 | 喵流 | Dify | Coze |
|------|------|------|------|
| 部署 | SaaS+私有 | 私有为主 | 仅 SaaS |
| 模型 | 国内外全面 | 国外为主 | 字节系为主 |
| 私有化 | ✅ Docker 一键 | ✅ 镜像 | ❌ |
| 中文优化 | ✅ | ⚠️ | ✅ |
| 字段加密 | ✅ AES-256 | ❌ | ✅ |
| MCP 工具 | ✅ | ❌ | ✅ |

---

### Q2: 喵流是免费的吗？

**A**: 喵流采用 Apache 2.0 开源协议，社区版**完全免费**，包括：
- 所有 38 个节点
- 所有 50+ 模板
- 不限制工作流数量

企业版提供：高级权限、审计 SLA、技术支持。

---

### Q3: 私有化部署需要什么环境？

**A**: 最低配置：
- CPU: 2 核
- 内存: 4 GB
- 磁盘: 20 GB
- Docker + Docker Compose

启动命令：`docker-compose up -d`

---

## 🛠️ 使用篇

### Q4: 如何调试工作流？

**A**: 三种调试方式：
1. **试运行** - 顶部工具栏 ▶ 按钮
2. **调试模式** - Ctrl+D 进入调试模式，在节点上点击设置断点
3. **执行日志** - 查看每次执行的节点级日志

---

### Q5: 工作流可以定时执行吗？

**A**: 可以。使用 **定时触发器** 节点 + Cron 表达式：
```
0 9 * * *       # 每天 9:00
0 0 * * 1       # 每周一
```

---

### Q6: 节点之间如何传递数据？

**A**: 使用 `{{节点名.字段}}` 语法：
```
{{trigger.text}}      # 触发器的 text 字段
{{search.context}}    # 知识库检索的 context
{{llm.answer}}        # LLM 节点的 answer 输出
```

---

### Q7: 工作流执行超时怎么办？

**A**: 默认 5 分钟。修改 `application.yml`：
```yaml
workflow:
  engine:
    timeout: 1800000  # 30 分钟
```

---

### Q8: 如何调用外部 API？

**A**: 使用 **HTTP 节点**：
- 支持 GET / POST / PUT / DELETE
- 支持 Bearer / Basic / API Key 认证
- 支持 JSON / form-data / raw body

---

## 💡 进阶篇

### Q9: 如何优化 LLM 调用成本？

**A**: 6 个技巧：
1. 使用更便宜的模型 (gpt-4o-mini vs gpt-4o)
2. 限制 maxTokens
3. 启用响应缓存
4. 批量合并请求
5. 使用 stopSequences 提前结束
6. 监控每日成本并设告警

---

### Q10: 如何让 LLM 调用结构化输出？

**A**: 三种方式：
1. **JSON 模式**: 模型选 `gpt-4o-mini` + `responseFormat: json`
2. **Function calling**: 定义 schema 让 LLM 调用
3. **后处理**: 在 prompt 要求返回 JSON，再用 JSON 节点解析

---

### Q11: 工作流可以嵌套吗？

**A**: 可以。两种方式：
1. **子工作流节点**: 引用另一个工作流作为节点
2. **Webhook 串联**: 通过 HTTP 调用另一个工作流的 Webhook

---

### Q12: 如何实现用户鉴权？

**A**: 喵流使用 **Sa-Token** + JWT：
- API 默认需要 Bearer Token
- 工作流配置 `permissions` 字段限制访问
- 支持 RBAC 角色权限

---

## 🔧 运维篇

### Q13: 如何监控工作流执行？

**A**: 三个层面：
1. **实时日志**: `/log/detail` 查看执行详情
2. **指标面板**: `/stat/dashboard` 查看 QPS/成功率/耗时
3. **告警规则**: 配置异常告警 (失败率 > 阈值)

---

### Q14: 工作流失败了怎么排查？

**A**: 排查步骤：
1. 进入 **执行详情** → 查看失败节点
2. 查看节点**错误日志**和堆栈
3. 使用 **调试模式** 重新执行观察
4. 检查上游节点的**输入变量**是否符合预期
5. 测试单节点: 在配置面板点击「单步测试」

---

### Q15: 如何备份工作流？

**A**: 两种方式：
1. **手动导出**: 工作流列表 → 点击 ⋯ → 导出 DSL (YAML)
2. **自动备份**: 启用自动备份到对象存储 (S3/OSS)

---

### Q16: 工作流可以版本管理吗？

**A**: 可以。每次发布都会创建版本快照：
- 查看历史版本
- 一键回滚
- 版本对比

## 🔌 集成篇

2. 选择 `Custom` 提供商
3. 填写 API 地址 (OpenAI 兼容协议)
4. 配置单价和上下文窗口

### Q19: 喵流支持 MCP 工具吗？

**A**: 支持！进入 **MCP 市场** → 安装所需工具。
- 官方提供 20+ 常用 MCP
- 支持私有 MCP 注册
- 工具调用记录在 **执行日志**

## 💰 计费篇

### Q21: 怎么计算 token 消耗？

**A**: Token 消耗 = 输入 + 输出。每个节点的消耗记录在：
- 执行详情 → 节点 → 显示 `promptTokens` + `completionTokens`
- 监控 → 成本统计

---

### Q22: 单次工作流最大成本？

**A**: 取决于：
- LLM 调用次数 × 单价
- HTTP 调用次数
- 存储/检索费用

默认**不设上限**，可在工作流配置 `maxCost`。

---

### Q23: 如何按部门核算成本？

**A**: 
1. 工作流归属到团队/部门
2. 执行时记录 userId
3. 在 **成本报表** 按团队/用户分组统计

---

## 🆘 故障篇

### Q27: 工作流执行卡住不动？

**A**: 排查步骤：
1. 检查 **执行状态** - 是否已超时
2. 查看 **节点日志** - 看最后执行的节点
3. 检查 **外部依赖** - LLM/HTTP 是否可访问
4. 检查 **数据库连接** - 是否连接池耗尽

---

### Q28: 节点报「不支持的节点类型」？

**A**: 原因：
- 节点插件未加载
- 节点类型名拼写错误

解决：
1. 检查节点类型定义
2. 重启服务加载插件
3. 联系管理员检查 `NodeRegistry`

---

### Q29: 数据库连接耗尽？

**A**: 修改 `application.yml`：
```yaml
spring:
  datasource:
    hikari:
      maximum-pool-size: 50
      minimum-idle: 10
```

---

### Q30: 如何重置管理员密码？

**A**: 通过 SQL：
```sql
UPDATE sys_user
SET password = '$2a$10$...'  -- BCrypt 加密的 "admin123"
WHERE username = 'admin';
```

或调用重置 API: `POST /api/auth/reset-password`
