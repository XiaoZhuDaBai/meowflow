# 喵流 (MeowFlow) - 可扩展性设计文档

> 本文档详细描述喵流平台的可扩展性设计，包括水平扩展、垂直扩展、功能扩展等多个维度

---

## 一、扩展性设计原则

### 1.1 核心设计原则

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           核心设计原则                                   │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  1. 换模型不改业务代码                                          │   │
│  │  ───────────────────────────────────────────────────────────────│   │
│  │  • 通过 ChatClient 抽象接口隔离差异                            │   │
│  │  • 新增模型只需实现 ChatClient 接口                            │   │
│  │  • 模型配置化，支持动态切换                                    │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  2. 换节点不改引擎                                              │   │
│  │  ───────────────────────────────────────────────────────────────│   │
│  │  • 通过 NodeRegistry 统一管理节点                              │   │
│  │  • 新增节点只需实现 NodeExecutor 接口并添加 @Component        │   │
│  │  • 自动注册，零配置                                            │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  3. 换业务不改基础设施                                          │   │
│  │  ───────────────────────────────────────────────────────────────│   │
│  │  • 基础设施层不依赖任何业务模块                                │   │
│  │  • common 模块独立演进，不影响业务                            │   │
│  │  • 线程池、限流、追踪等能力可复用                            │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  4. 水平扩展优先                                                │   │
│  │  ───────────────────────────────────────────────────────────────│   │
│  │  • 无状态服务设计，支持水平扩展                                │   │
│  │  • 分布式缓存减少数据库压力                                    │   │
│  │  • 消息队列实现异步解耦                                        │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

│  │                                                                   │   │
│  │      @Autowired                                                  │   │
│  │      private CacheManager cacheManager;  // 本地缓存              │   │
│  │                                                                   │   │

│  │          String key = "workflow:definition:" + workflowId;        │   │
│  │                                                                   │   │
│  │          // 1. 查本地缓存                                       │   │
│  │          Cache localCache = cacheManager.getCache("workflow-def");│   │
│  │          WorkflowDefinition def = localCache.get(key);          │   │
│  │          if (def != null) return def;                          │   │
│  │                                                                   │   │
│  │          // 2. 查 Redis                                        │   │
│  │          def = (WorkflowDefinition) redisTemplate.opsForValue()  │   │
│  │              .get(key);                                         │   │
│  │          if (def != null) {                                    │   │
│  │              localCache.put(key, def);  // 回填本地缓存         │   │
│  │              return def;                                        │   │
│  │          }                                                      │   │
│  │                                                                   │   │
│  │          // 3. 查数据库                                        │   │
│  │          def = database.getDefinition(workflowId);              │   │
│  │          if (def != null) {                                    │   │
│  │              redisTemplate.opsForValue().set(key, def, 1, TimeUnit.HOURS);│   │
│  │              localCache.put(key, def);                          │   │
│  │          }                                                      │   │
│  │                                                                   │   │
│  │          return def;                                            │   │
│  │      }                                                          │   │
│  │  }                                                              │   │
│  │                                                                   │   │
