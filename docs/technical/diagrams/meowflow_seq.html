9. POST {base}/v1/chat/completions（含 messages/temperature/max_tokens，Agent 可带 tools/tool_choice）
11. 成功返回；异常在节点级：重试(≤10,500ms退避)→fallbackValue 兜底→取消(CancellationToken 50ms 轮询)
13. EdgeRouter 按 DEFAULT/CONDITION/ERROR 边推进下游；失败节点只走 ERROR 边否则截断；JOIN 按 ALL/ANY/N_OF_M 放行
15. vector(Embedding→PGVector 余弦 1-(v<=>q)) + keyword(当前占位)；SearchPostProcessor 去重/阈值/RRF/上下文拼装
17. Agent 节点到达：从 MCPToolService.getAllTools() 构建 OpenAI function schemas（function-calling 策略）
19. 再次经路由+熔断发起带工具定义的对话请求
21. AgentExecutor/ToolExecutor 调用 MCPToolService.executeTool；单工具异常捕获为 {error} 不中断
23. 工具输出返回给 Agent 节点
25. 引擎收集所有 isEnd 节点输出 merge 为工作流最终输出；未执行节点标记 SKIPPED
27. ExecutionService 更新状态/输出/成本；取消关联 HumanTask；@Async 失败亦落 failed 状态
2. 写入 Execution(pending)；经 Spring 代理自调用 @Async(workflowExecutorPool) 切线程池
4. DAG：dagCache(workflowId:version) 命中或 DAGSorter 拓扑排序；触发节点入就绪队列
6. Trigger/普通节点输出写入 context.nodeResult；recordStarted 记录开始状态
8. ChatModelRouter 按 AIProvider 内置表/前缀匹配 → ChatClient；Resilience4j 熔断器包裹；成功后 ModelHealthStore.markSuccess
10. 返回 content/model/tokens/tool_calls/latency；失败→熔断计数，熔断开路→fallback 响应
12. nodeFinished 事件→RedisStream；NodeExecution 持久化；enableStream 时经 SSE 推送 nodeStreamDelta 增量
14. KnowledgeSearch 节点：kbId/query(支持${}变量)/topK=5/阈值0.7/mode=hybrid|vector|keyword
16. 返回 {chunkId,documentId,content,score,metadata}[] → 节点输出供下游 LLM/Agent prompt 引用
18. extraParams={tools, tool_choice:"auto"} 再次调用 gateway（JSON ReAct 策略则输出 {action:tool|final} 文本协议）
20. 返回 message.tool_calls[{function:{name,arguments}}]（原生模式）
22. MCPToolRegistry → StdioAdapter(本地进程)/SseAdapter(远程SSE) 执行；参数类型转换+必填校验
24. 追加 assistant(tool_calls)+tool(结果) 消息，循环至无 tool_call/final/答案或达到 maxIterations(默认5)
26. 返回 ExecutionResult(status/output/costMs/costToken/costAmount)；成功/失败/取消计数并清理取消注册
28. RedisStream 事件供前端实时(SSE)；同步执行直接返回 ExecutionResponse，异步则轮询/事件获取结果
