# MeowFlow Infra - 基础设施模块设计文档

> 本文档详细描述喵流平台的基础设施模块（MeowFlow-infra）的设计与实现

---

## 一、模块概述

### 1.1 模块定位

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          MeowFlow-infra 模块定位                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │

│                                                                          │

│  │                                                                   │   │
```

### 1.2 核心设计理念

```
┌─────────────────────────────────────────────────────────────────────────┐
```

### 3.2 模型路由与熔断

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        模型路由与熔断设计                                  │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  路由流程                                                        │   │
│  │  ───────────────────────────────────────────────────────────────│   │
│  │                                                                   │   │
│  │   请求 ──► 解析模型 ──► 匹配供应商 ──► 调用 Client              │   │
│  │                   │                                              │   │
│  │                   ▼                                              │   │
│  │              按前缀匹配                                          │   │
│  │                                                                   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  熔断降级                                                        │   │
│  │  ───────────────────────────────────────────────────────────────│   │
│  │                                                                   │   │
│  │  熔断器状态：                                                    │   │
│  │  • CLOSED：正常调用                                              │   │
│  │  • OPEN：熔断中，直接降级                                        │   │
│  │  • HALF_OPEN：探测恢复                                          │   │
│  │                                                                   │   │
│  │  降级策略：                                                      │   │
│  │  1. 主模型失败 → 尝试备用模型                                    │   │

│  │  3. 全部失败 → 返回友好提示                                      │   │
│  │                                                                   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │

│  │      openai:                                                     │   │

│  │        fallback: gpt-4o-mini                                     │   │

│  │        enabled: true                                            │   │
│  │        failure-rate-threshold: 50                                │   │
│  │        wait-duration-in-open-state: 30s                         │   │
│  │                                                                   │   │
```

### 7.2 混合检索融合

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      混合检索融合算法                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  RRF (Reciprocal Rank Fusion)                                    │   │
│  │  ───────────────────────────────────────────────────────────────│   │
│  │                                                                   │   │
│  │  RRF_score(d) = Σ 1/(k + rank_i(d))                             │   │
│  │                                                                   │   │
│  │  其中：                                                          │   │
│  │  • k: 常量（通常为 60）                                          │   │
│  │  • rank_i(d): 文档 d 在第 i 个通道中的排名                       │   │
│  │                                                                   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  混合检索示例                                                     │   │
│  │  ───────────────────────────────────────────────────────────────│   │
│  │                                                                   │   │
│  │  1. 并行执行向量检索和关键词检索                                  │   │
│  │  2. 对结果按 RRF 算法融合                                        │   │
│  │  3. 取 Top-K 返回                                                │   │
│  │                                                                   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

## 十三、模块定位

**infra 是库模块，不是服务模块。**

- 业务模块（workflow、template 等）通过 pom 依赖引入 infra
- infra 的 Bean 由 Spring Boot 自动装配机制加载，无需 `@Import`
- 生产部署时 infra 不单独运行，作为业务模块的一部分
- 调试时可通过 `MeowFlowInfraApplication` 在 IDE 中查看所有 infra Bean

详见 `docs/technical/architecture.md` 第十二章。
